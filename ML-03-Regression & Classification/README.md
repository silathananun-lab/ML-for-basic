# Regression & Classification
### Regression 
Regression is Predict a continuous numerical value (Regression task)
### Classification
Classification is Predict discrete categorical values/labels (Classification task)
* Simple Linear Regression

Simple Linear Regression is the process of finding the relationship between 2 variables to use predic result 
* Multiple Linear Regression  

Multiple Linear Regression is finding the relationship similar to Simple Linear Regression but different the use a Multiple values to predict result
* Age prediction

Age prediction is Analyze data to estimate or assess a person's age.
